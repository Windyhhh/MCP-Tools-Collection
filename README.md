# 🔧 MCP Tools Collection | MCP 工具合集

> **Collection of Model Context Protocol (MCP) server implementations. Various MCP tools for extending AI assistant capabilities, including file operations, web search, database access, and custom integrations.**
>
> Model Context Protocol（MCP）服务器实现合集。各种 MCP 工具，用于扩展 AI 助手能力，包括文件操作、网页搜索、数据库访问和自定义集成。

---

## 🌟 Features | 核心特性

- **MCP Protocol** — Model Context Protocol compliant
- **Multiple Servers** — Various MCP server implementations
- **Tool Integration** — Extend AI assistant capabilities
- **Standard Interface** — JSON-RPC based communication
- **Cross-Platform** — Works with Claude, Cursor, etc.

---

## 🚀 Quick Start | 快速开始

```bash
# Install MCP CLI
npm install -g @modelcontextprotocol/cli

# Configure MCP server in your AI client
# Add to ~/.config/claude/claude_desktop_config.json:
# {
#   "mcpServers": {
#     "my-server": {
#       "command": "python",
#       "args": ["server.py"]
#     }
#   }
# }
```
